# ADHD儿童VR音乐游戏多模态实验数据

## 数据内容

- 行为表现：12 名被试在 T1 至 T5 五个条件下的正确数、错误数、误中数和过击数，共 60 条长表记录。
- 主观喜爱度：12 名被试在五个条件下的 5 点评分，共 60 条长表记录。
- 任务参数：五个关卡的左小鸟、右小鸟、蝙蝠和怪兽四类行为指标理论最大值。
- fNIRS：T1 至 T5 每个条件 12 个 MATLAB 5.0 `.mat` 文件，共 60 个文件。

## 条件与实验背景

报告明确给出第一关至第五关与 T1 至 T5 的一一对应关系：第一关为 T1、第二关为 T2、第三关为 T3、第四关为 T4、第五关为 T5。

报告中的实验条件包括：预实验比较视听同步的音乐游戏与视听不同步的非音乐游戏；实验一比较 60 BPM 与 120 BPM 音乐速度条件，并对任务量差异进行标准化；实验二比较规整节奏与附点、切分节奏条件，并分析错误类型。报告同时强调，不能只根据 T1 至 T5 的文件夹名称推断音乐速度或节奏类型。因此，本仓库保留 T1 至 T5 作为数据索引，不额外建立未经原始文件直接证明的实验条件映射。

## fNIRS采集与处理背景

报告记载，近红外数据由 Cortivision PHOTON CAP 无线便携式 fNIRS 系统采集，使用 760 nm 和 850 nm 双波长近红外光；26 个通道由 8 个发射极和 9 个探测极构成，光极间距约 3 cm，主要覆盖前额叶区域。原始光强信号依据修正的比尔—朗伯定律转换为 HbO 与 HbR 浓度变化，研究主要以 HbO 指标进行分析。

报告描述的预处理流程包括：五阶多项式回归去除低频漂移、三阶巴特沃斯 0.01–0.08 Hz 带通滤波、TDDR 运动伪迹校正，以及依据血流动力学响应函数进行任务事件时间对齐。报告还说明事件表应包含 `condition`、`onset`、`duration` 和 `event_type`，通道说明应记录光源—探测器关系、MNI 坐标、解剖定位和 ROI。

本数据包中的 MAT 文件可识别到 `nirsdata`、`oxyData`、`vector_onset`、`probe2d`、`probe3d` 及预处理设置相关字段。由于原始项目文件夹未包含独立的事件标记表、通道说明文档、预处理脚本、软件版本记录或运行日志，本次整理不从其他版本补入，也不对 MAT 内部字段作未经验证的拆分或解释。

## 主观体验资料范围

报告说明，主观体验采用关卡完成后的 5 点喜爱度评分与半结构化访谈相结合的方式采集；访谈内容包括游戏体验、情绪状态、偏好程度和改进建议，并应保留原始表述与主题编码的对应关系。报告还说明，这些资料反映的是儿童完成具体关卡后的即时感受和任务可接受性，不应作为独立疗效量表解释。

当前原始项目文件夹仅提供喜爱度评分表，未包含独立的半结构化访谈录音、转录文本或主题编码文件，因此本数据包只收录喜爱度量化数据。

## 数据质量

- 行为表中 `sub-009` 在 T5 条件下的 `over_hit_count` 为空；CSV 保留该空值。
- 未发现重复的 `subject_id + condition` 记录。
- 喜爱度评分均在 1 至 5 范围内。
- 三份 CSV 的数值已与对应源 Excel 逐项核对。
- 文件完整性可通过 `metadata/checksums_sha256.txt` 核验。

## 伦理、隐私与使用范围

报告将脱敏后的结构化行为数据、实验条件参数和部分统计特征列为可在一定范围内共享的数据；将原始 fNIRS 数据、完整访谈转录文本、原始音视频和详细健康信息列为高敏感数据，要求采用申请审批或受控共享。由于本数据包包含原始 fNIRS MAT 文件，在获得数据管理方明确授权并落实相应访问控制之前，不应将仓库设为公开。

本数据仅适用于研究与方法复核，不能直接用于个体诊断、临床疗效判断或自动化决策。二次分析时应保持源文件只读，在副本或衍生数据层完成处理，并记录所用文件、参数、软件版本和分析规则。
